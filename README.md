## 三件核心本事

### 📚 你的私人课程表
在学的课全部钉在一个列表里：封面、集数、总进度环。打开应用就自动去 B 站历史里对账，精确恢复到上次看到的那一秒。

### 🕵️ 跳跃/回看检测
从第 29 集一脚油门倒回第 1 集？同一集里从 40 分钟摁回 5 分钟？这些操作都会被记进跳跃历史——不是抓你摸鱼，是让你一键回到原位，复习不迷路。

### 📱 扫码即登录
第一次用，不用研究 Cookie 是什么——B 站 App 扫一扫，就好。

## 🎁 正片之外的小彩蛋

- 🎉 **通关撒花** —— 最后一集看完的瞬间，进度环镀金、彩带落满全屏。这门课，你通关了。
- 🍅 **番茄钟** —— 点一下开始专注，红色番茄环和进度环并排转；今日专注时长按天累计，学没学、学了多久，数据不会说谎。

## 快速开始

### 方式一：直接使用

1. 到 [**Releases**](../../releases) 下载最新压缩包，解压到任意目录
2. 双击 `B站课程进度追踪.exe`（无需安装 Python）
3. 首次使用：右上角 ⚙ → **扫码登录**，用 B 站 App 扫一下即可
   （扫不出来？展开"手动粘贴 SESSDATA（备用）"，从浏览器 Cookie 里复制粘贴）

> 仓库本身不含 exe 和任何个人数据（凭据/观看记录/封面缓存均已通过 `.gitignore` 排除）；想自己打包出 exe 见下方「方式三」。

### 方式二：源码运行

```powershell
# 首次先安装依赖
安装依赖.bat          # pywebview / Pillow / PyInstaller / qrcode

# 源码启动（数据目录与打包版共用）
py -3 src\app.py
```

### 方式三：自己打包

代码改动后双击 `scripts/打包.bat`（等价 `py -3 scripts/build.py`）。应用正在运行会自动帮你关掉，打包完自动启动新版，数据不受影响。采用 `--onedir + --noconsole`：启动快、无黑窗口、前端单文件内嵌。

## 工作原理

```
pywebview 窗口 (WebView2)
   └── 单文件前端 index.html
         └── 本地 HTTP 服务 (127.0.0.1:8765，标准库 http.server)
               ├── B站历史 cursor 接口（HTTPS 长连接复用 + 分页命中即停）
               ├── 扫码登录（官方 WEB 二维码通道，凭据不落日志）
               ├── 封面图代理（强制 IPv4 + 本地缓存，规避 IPv6 挂起）
               └── 本地存储 tracked_videos.json（原子写 + 线程锁）
```

应用只在本机运行，所有请求从你的电脑直接发往 B 站官方接口，没有任何中间服务器。

## 隐私与安全设计

**你的秘密它守得住**——这门课是"考研数学"还是"钓鱼入门"，只有你自己知道：

- **凭据加密存储**：SESSDATA 通过 Windows DPAPI 加密保存于 `.sessdata.bin`，只有当前 Windows 账户能解；拷走文件或换账户都读不出来，磁盘上不存在明文
- **本地数据最小化**：`tracked_videos.json` 和 `focus.json` 只存数字（bvid、集数、秒数、时间戳）——课程标题、UP主、封面、分P列表一概不落盘，每次启动实时从 B 站拉取；就算文件泄露，也看不出你在学什么
- **本地接口防护**：校验 `Host`（防 DNS rebinding）与 `Origin`/`Sec-Fetch-Site`（防其它网页 CSRF 调用本地端口）
- **凭据文件不可通过 HTTP 读取**：`.sessdata*` 与所有隐藏文件被静态服务直接拒绝（404）
- **提交防护**：仓库内置 pre-commit 钩子，凭据/数据/打包产物一旦进入暂存区立即拦截
- SESSDATA 仅用于调用 B 站 API，不回显、不上传、无任何第三方服务

```

├── src/                      ← 源代码（app.py / server.py / index.html）

├── docs/                     ← README 截图
├── hooks/                    ← pre-commit 隐私拦截钩子（core.hooksPath 已指向这里）
├── scripts/
│   ├── build.py + 打包.bat    ← 一键打包
│   ├── 启动.bat               ← 开发模式启动
│   ├── 启动.sh                ← Linux 启动
│   └── 安装依赖.bat           ← 安装 Python 依赖
```

本机运行/打包后还会生成 `B站课程进度追踪/`（成品应用 + 全部数据，已被 `.gitignore` 排除，不会上传）：

```
B站课程进度追踪/
├── B站课程进度追踪.exe        ← 主程序（无黑窗口）
├── _internal/                ← 运行库（打包自动生成，勿动）
├── .sessdata.bin             ← B站凭据（DPAPI 加密，仅本机可解）
├── tracked_videos.json       ← 追踪列表与进度（仅数字，无标题/UP主）
├── focus.json                ← 番茄钟每日专注秒数（仅数字）
├── course_data.json          ← 旧版遗留数据（可手动删除）
└── covers/                   ← 封面图本地缓存（文件名为内容哈希）
```

> 备份/迁移：整个 `B站课程进度追踪\` 文件夹拷走即可，全部数据都在里面。

## 常见问题

| 问题 | 说明 |
|---|---|
| 扫码登录没反应/被风控 | 刷新二维码重试；多次失败可展开"手动粘贴 SESSDATA（备用）"走老路 |
| Tab 显示 "BV…XXXX" 占位 | 隐私设计：标题不落盘、实时从B站获取；断网或登录失效时暂缺，恢复后自动补齐 |
| 打开慢 / 杀毒报警 | PyInstaller 打包的程序可能被误报，添加信任即可 |
| 进度同步失败 | 多为 SESSDATA 过期（约 1 个月），重新扫码或粘贴即可；可访问 `http://127.0.0.1:8765/api/diag` 诊断连通性 |
| 开机后提示"离线模式" | 开机瞬间网络未就绪所致，联网后应用会自动重试恢复，无需手动操作 |
| 最近历史里找不到视频 | B 站历史接口可能过滤短时观看，在 B 站网页播放该视频 30 秒以上再刷新 |
| 窗口缩放 | 鼠标移到窗口四边/四角出现缩放光标后拖拽，最小 720×560 |
